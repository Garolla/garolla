## It's-a me, Ema! 👋

Tech Lead & Senior Software Engineer at Intesa Sanpaolo, where I coordinate the design and development of the core banking data platform serving 16 million customers, built on Flink, SQL and BigQuery. 
I also led the data migration strategy, designed to move 4 million customers to IsyBank, the group's new digital bank (Java, PostgreSQL, Teradata).

Before that, five years at Reply. iOS Engineer (Swift) and then Tech Lead of the Vodafone Station App (2M+ downloads, Red Dot Award 2019), where I was the customer's single point of contact and led the development team. 
My last project there was edge computing for Electrolux Professional: embedded Java on an IoT gateway, processing and filtering sensor data from ovens, blast chillers and fridges on site, so that only what mattered reached Azure IoT. Lower ingestion costs, better cloud performance.

On the AI side I build and run my own things end to end: RAG pipelines and LLM agents with Python on FastAPI, self-hosted on my own infrastructure, with observability I set up myself. I ship most of my code with agentic tools (Claude Code), and the hard part is not the speed: it is not building the wrong thing quickly.

M.Sc. in Computer Engineering, Politecnico di Torino. Qualified professional engineer (Italian State Exam). Based in Turin, Italy.
